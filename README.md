# 👋 Hi, I’m Oluwafemi — On-Chain Builder & Web3 Developer

I’m a blockchain developer passionate about building open, permissionless, and composable tools across multiple chains. My work focuses on creating real, functional on-chain products that solve problems around payments, identity, tokens, and user experience — with a bias toward emerging markets.

## 🚀 What I Build
I work across several ecosystems including **Celo**, **Base**, **Stacks**, **Ethereum**, and other EVM chains. My projects typically involve:

- **Real-world payment rails** — stablecoins settling into airtime, data, electricity, and bank transfers
- **Dapps with full wallet integration** (EVM & non-EVM: MiniPay, Xverse, Leather, WalletConnect)
- **Smart contract systems** in Solidity and Clarity — vaults, lending, payroll streaming, reputation
- **On-chain dashboards & indexers** (Chainhooks, TVL, contributor analytics, token discovery)
- **Developer SDKs** published to npm so other builders can skip the boilerplate

## 🔗 Chains I Build On
- **Celo** — stablecoin payments, MiniPay mini-apps, onchain reputation
- **Base** — L2-native apps, Farcaster miniapps, growth dashboards
- **Stacks** — Bitcoin-secured apps, sBTC payments, BTCFi lending, STX vaults
- **Ethereum & other EVM chains** — contracts, tooling, cross-chain integrations
